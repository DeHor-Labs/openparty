Contact

OpenParty is maintained by Nikolas de Hor, a developer based in Goiânia, GO, Brazil. For questions about the project, bug reports, feature requests or privacy matters, write to nikolasdehor79@gmail.com.

Repository and issues

OpenParty's code is public. Technical bugs, feature suggestions and questions about the WebSocket protocol can be opened directly as an issue on the GitHub repository, which is usually faster than email for technical matters.

What to include

When reporting an issue, please describe the browser used, the video URL (without sensitive data), the approximate time, and what you expected versus what happened. Since rooms live only in the server's memory and are removed once the last person leaves, a room's history cannot be recovered after it closes.

To understand how room data is handled during a connection, see the Privacy Notice.
